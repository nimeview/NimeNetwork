# Дальнейшие Улучшения

Сейчас проект уже рабочий, поэтому roadmap дальше скорее про удобство и устойчивость.

## Сеть И Control Plane

- автозапуск всего сервера без ручных foreground процессов
- backup/restore с аккуратной остановкой сервисов
- более чистый HA/replication story для control plane

## DNS

- `AAAA`
- `SRV`
- `TXT`
- health-aware записи
- более богатая диагностика конфликтов имён

## Клиент

- ещё сильнее упростить сценарий после перезагрузки
- готовые installers
- удобные команды вокруг встроенных сервисов

## Портал

- фильтр по группам
- отдельные страницы сервисов
- статус доступности
- улучшенный поиск

## Сервисы

- права доступа для storage
- более удобное редактирование wiki
- учёт ролей и аудита в ledger

## Документация

- автоматическая сборка `mdBook` в CI
- публикация статической HTML-версии
- больше примеров под Linux/macOS/WSL
