# Улучшения

Сеть уже работает. Дальше главная задача — сделать её удобнее и надёжнее.

## Самый высокий приоритет

- автозапуск клиента одной командой на macOS и Linux
- более сильный `nime-client health` с проверкой peers и более понятными ошибками
- `nime-client open portal` без ручного `--port`
- разделение документации на пользовательскую и админскую

## Улучшения сервера

- более аккуратные логи и restart policy по умолчанию
- интеграция `nime-dns` и `nime-portal` с registry API, а не прямым SQLite

## Улучшения registry

- фильтрация и поиск как отдельные CLI-команды
- category и visibility
- health status для сервисов
- позже полноценный write API, а не только read API

## Улучшения DNS

- `AAAA`
- `SRV` и `TXT`
- более понятная диагностика отсутствующих записей
- метрики и опциональный кэш

## Улучшения портала

- явное отображение порта и протокола
- группировка по тегам или категориям
- отдельная страница сервиса
- health badges
- каталог peers

## Кроссплатформенность

- более чёткие заметки по macOS DNS
- helper для Linux client autostart
- план для Windows позже, когда клиентский слой стабилизируется
- CI release pipeline поверх локального packaging

## Рекомендуемый порядок следующих шагов

1. несколько сценариев backup/restore с остановкой сервисов
2. checksums и version stamping для release-архивов
3. CI release pipeline
4. автоматическая установка launchd/systemd конфигов из release-пакета
5. packaging под macOS и Linux из одного workflow
